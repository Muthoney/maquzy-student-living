HAVENLY Student Living — enhanced student accommodation school-project demo

FILES:
- index.html: landing page and filters
- style.css: premium responsive styling
- script.js: sample listing/filter/navigation data
- residence.html: accommodation details page
- details.css: details-page styling
- details.js: details content and downloadable price-list logic

RUN:
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open index.html using Live Server (recommended), or open index.html in a browser.
4. Click a residence card to open its own detail page.
5. Use the “Download price list” button on a detail page to save a CSV price list (opens in Excel).

IMPORTANT:
All accommodation listings, amenities, and prices are fictional sample data for the school project. Replace them with verified information before real use. No database or server-side booking is connected yet. This is not an official MKU website.
